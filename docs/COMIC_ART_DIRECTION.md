# The rehearsal storyboard

The comic supports the app's central idea: trying a conversation before having
it in real life. The three scenes correspond to the flat viewing, interview and
boundary-setting samples. The recurring character, storyboard frames, clapperboard,
editable “Take 02” speech bubbles and crossed-out hesitation make the practice
theme explicit. The artwork does not predict how another person will respond.

The illustration was created and restyled with the built-in image-generation tool.
The current web asset is `public/images/rehearsal-comic-modern.webp`
(1536 × 1024, about 184 KiB). The initial WebP is retained as a reference asset.
Text, speech bubbles, scene labels and production annotations are HTML/CSS so
they translate into English, German and Spanish and remain accessible text.
The original generated PNG is preserved outside the repository; the WebP is
only a web export, with no changes to the illustration's composition.

On smaller screens the comic starts collapsed so the source picker is easier
to reach. An explicit Show comic button opens larger, horizontally scrollable
panels with readable captions. The same region supports keyboard scrolling;
the desktop layout continues to show all three panels. Nathan's original photo
and the show's inspiration are explained in the separate About section.
